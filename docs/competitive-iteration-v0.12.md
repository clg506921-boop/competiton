# v0.12：有期限约束的资源绕路与三版选优

2026-10-22。当前保留v0.12作为后续联调候选：固定图平均得分恢复至基线，并保留更及时的事件响应。还没有战胜全部官方陪练，也未达到正式封存条件。

## 代码改动与学习点

原资源规划在存在未完成任务时会排除不增加任务进度的资源目标。这样只剩一个远处reach任务时，附近可得分的资源也不能竞争。现在仅当采集任务已满足、只剩一个reach目标，并证明“先拾取，再到达目标，最后仍预留20控制Tick”时，允许该资源参与原有收益/距离与两站前瞻比较。

20Tick是冻结的安全余量，不是对未知地图、敌方行为或新事件的绝对保证；每帧重算。时间不足、路径无证据、资源分已封顶、仍有采集任务或存在多个未完成reach时，继续采用任务优先。只做导航可行性判断，绝不提前记任务完成。新增6项边界验证覆盖20/19Tick边界、路径缺失、采集任务优先、多个reach等；共14组原生回归及ROS构建通过。

保留v0.11的单worker、单待发请求、新公告优先及已知DeepSeek非思考规则；Schema和语义安全门未放宽。生效/结束等后续公告的关联解释仍有拒收，下一轮应补真实上下文样本，而不是忽略校验。
