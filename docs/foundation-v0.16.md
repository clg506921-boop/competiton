# v0.16 基础功能与规则兼容候选（2026-10-23）

基于 v0.14 已验证策略；v0.15 资源竞争研究完整归档，未晋升。优先检查通信、恢复、异步和可交付性。

- 规则 v1.1 的有效伤害上限 500 集中于 rules.hpp；感知 score.effective_damage 始终直接使用，不二次结算死亡或击杀；本地战斗评估尚不完整预测多人击杀分摊。
- 新 session_id 首帧立即清空并切换；旧场已退休帧丢弃。同 ID 回退丢弃，符合重开必须新 ID 的正式协议。
- 终局仍核对上一动作回执，不再发终局动作；未实际发布的动作不能被隐式 WAIT 回执确认。
- 本地动作年龄超过 Tick 预算时丢弃；预算来自赛前配置或当前规则阶段默认值，不声称测得网络端到端延迟。DDS 返回超过预算单独记录。
- 规划、编码、发布、发布后处理分别计时；发布后准备与日志耗时可审计。
- ROS Fast DDS 发布默认异步，QoS 仍为 RELIABLE / VOLATILE / KEEP_LAST(1)；异步仍可能受 history 背压影响。
- 赛前私有 JSON 支持 v1.1、quota=0 不限、可选 max_ticks/tick_ms；不支持更改策略权重。stage 0 诊断仅 WAIT，无 AI，官方练习包没有阶段 0，使用合成公开输入验证。
- 待验收：Release、ROS、ASan/UBSan、真实裁判闭环、恢复、异步故障、Docker 镜像及录屏。
