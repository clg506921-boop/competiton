# v0.15 可见竞争下的资源估值候选

基于 v0.14。本轮只改变导航资源估值，不更改伤害计分或 v1.1 参数。验证状态见本轮状态卡和原始日志。

对当前公开感知中的存活对手，使用已知墙、已知分裂墙与乐观可穿越的未知格计算到资源的名义距离。最多三车，不保留视野外敌车的位置或推演路线。自身的临时反摆动避让不算成对手遇到的实体墙。

资源的到达折减系数：本车早于最近可见对手为 1；同 Tick 为 1/2；再迟一 Tick 为 1/3，依次递减。这是规划启发式，不是校准过的概率，不证明对手会去采集，也不删除资源记忆。没有可见竞争证据时不折减。

首站与第二站分别按名义到达时刻折减，第二站不能继续按“资源一定还在”估值。两个资源的四种采集结果分别应用主分封顶与任务门槛，再加权；到点任务只依赖实际访问，不因同格资源不确定而折减。任何预测都不改写官方累计资源或任务完成记录。

导航候选保留名义收益，另列估计收益。选目标、战术比较使用估计量；日志 `navigation_goal` 同时记目标、步数、名义／估计收益、折减系数、最近可见竞争距离及排序值，`visible_resource_rivals` 记录使用的当前对手数。

旧资源仍保留直至完整公开视野证实消失。按时间直接丢弃可能损失可回收资源，因此本轮没有增加 TTL。平局的最终地图索引裁决、任务点临时占位及 P7 探索竞争不在本轮改动范围内。

旧规则下的导航实验、ROS／真实网关验证必须分别列明。小型无战斗试验只能验证这一机制，不能证明正式地图胜率或 v1.1 适配。正式参数继续用同一份私有接入文件，算法折减系数不作为现场可调字段。
