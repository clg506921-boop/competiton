# 主动事件收益与短程追击（v0.5）

日期：2026-10-22。延续已核验 v1.1.1，参考 v1.1.2，比赛规则和通信协议优先。本轮在自研 C++17 / bot_core 中补齐 P6 主动事件机会、P7 短程追击的保守版本；Ubuntu 内完成编译、ROS 无关运行时测试与定向回归。裁判程序、官方配置和原包未修改。

## 新能力

任务和有价值资源仍优先。没有这些目标时，程序依次考虑已解释且已生效的回血/堡垒机会、正收益短程追击、探索与 WAIT。所有机会仍经过原有事件期限避险、同时攻击风险和最终动作合法性检查；不允许用“将来回血”抵消当前 Tick 的致死攻击。

### 成功入点才有治疗

从 LLM 已验证的天使事件提取公共点位、开放窗口、治疗速率和时长。按路径估算成功入点动作 K，K 必须早于入口截止；新治疗区间为 [K,K+heal_ticks)，点消失不截断已获得效果。计算现有治疗预计能覆盖的血量，只为新增收益绕路。

满血、已有治疗足够、赶不上开放窗口时不主动入点。已经站在点上不能 WAIT 冒充入点；只有安全且确有新增收益时才规划“离开、重新进入”两个 MOVE。实际触发仍需要后续结构化成功回执，实际 HP 始终使用感知值。临近软时长时，不为最后动作之后无法用于控制的治疗绕路；软时长已经过去则继续处理当前有效感知。

### 堡垒驻留与防御可以同时成立

只使用当前事件记录中经连续回执确认的驻留进度。缺帧不补算，离开或死亡清未完成进度。把移动入区当 Tick 的驻留计入所需控制步数，但达标动作 K 的增益只能从 K+1 攻击，且 K+1 必须早于公共效果截止。已拿到增益后停止为它驻留。

在区内可选择 WAIT 或 DEFEND 累计驻留，敌方威胁下仍使用防御减伤比较。若 ATTACK 后能够存活且仍在区内，也可保留同一驻留机会值；阵亡的攻击不计驻留收益。已知爆炸/分裂将在计划途中或驻留期间发生时，不把该路线当作安全收益。

### 追到攻击位置，不追旧坐标

只考虑当前可见敌车，不读取全图，也不追记忆中已经消失的敌人。最多规划 4 步到一个未被车辆占据、按当前武器模型能攻击的位置；攻击方向和范围复用既有战斗模块，普通攻击不自行加入障碍遮挡规则。

先在可用的最近攻击位置间比较收益和下一位置风险，每 Tick 重新规划。这样不会为了“下一步暂时安全”不断改追更远的攻击位。反伤、敌车保护未知/生效、伤害分封顶且没有对应任务、来不及在软时长前攻击时，不产生追击收益。

balanced 比较正净收益；collect 还要求未来保守场景可击杀或已确认模型下没有反击。敌车未来位置和意图都未知，不能把路径终点的一次假设命中当成保证。

## 机会值与硬规则的区别

资源/伤害公式、动作合法性、效果区间和结算顺序来自规则；事件机会值是内部策略估计，不增加官方分数，不覆盖官方 HP，不声明命中概率。当前固定估计如下，后续只能在封存前结合比赛数据调整。

| 项目 | 固定做法 |
| --- | --- |
| 共同比较跨度 H | 资源/任务距离截到 1–5 Tick；无目标取 1，保持 v1.1.1 |
| 治疗价值 | 新增有效 HP / 100 × 4，再按控制步数折算到同一 H |
| 堡垒价值 | 基础机会值 0.5，按取得后最多 10 Tick 的剩余有效期折减，再按驻留/移动步数折算 |
| 追击价值 | 一次保守攻击的分值增量 × 0.5 × H / 接近步数；0.5 是折扣，不是实测命中率 |
| 有界计算 | 最多 16 个主动事件、每个最多 64 个目标格；事件路径不超过 12 步，路径加驻留不超过 32 Tick |

当前只主动争取已经生效的机会；不提前蹲守未来事件，不为主动收益等待暂时封闭的通道。堡垒估计尚未按潜在敌人数和完整交火收益优化；追击仍是假设对手短时间不动，不包含完整多车预测、集火或最优对抗搜索。

## 代码与接口

- opportunity.hpp / opportunity.cpp：ROS 无关的机会类型与治疗/堡垒时间、收益估计，编入 bot_core 静态库。
- EventMemory::opportunities：只从已验证模型事件和连续结构化回执产生类型明确的机会，不解析事件原文。
- BotRuntime::tactical：加入路径检查、主动入点/驻留、最近攻击位追击；沿用原有当前受击和下一位置风险模型。
- opportunity_tests.cpp：18 项新增测试。

仍只有 balanced / collect 两个正式 decision_type，配置只在启动读取；本轮未增加现场调参、人工动作、目标坐标或策略热切换入口。AI 网关、来源去重和资格请求调度没有更改，没有增加网络调用。
