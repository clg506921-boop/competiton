# v1.2适配记录

依据用户于2026-10-26提供的赛事规则v1.2，与v1.1全文比对。规则尚未终稿，按用户说明后续主要补充。

- 编程语言不限，推荐C++17及以上：本项目C++17。
- 容器镜像不再强制提交：保留可选Docker部署，验收和正式提交以完整可运行仓库为主。
- 堡垒多数位于(11,11)至(13,13)，但有地图变化：生产只使用校验后的模型区域；补偏移区域与标准10Tick驻留/50Tick存在的验证。
- 复活选点明确曼哈顿分层、上右下左、障碍只限制落点、资源格可落点、多车A到D：已有辅助模型及测试覆盖，主路径不从预测位置定位。
- 报告补齐AI协作、截图、逻辑和指令；提交仓库路径及版本须与现场运行一致，后续按官方链接与协作者要求交付。

评分机制未在本轮调整。当前只收到新规则PDF，现有官方练习裁判仍为v1.1归档；其联调结果须标明来源，不能称为官方v1.2裁判验收。工具默认支持v1.2，并允许显式选择已审核的v1.1练习配置；未经审核的v1.3等版本继续拒绝。
