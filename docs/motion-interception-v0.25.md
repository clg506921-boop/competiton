# v0.25 短时追击拦截候选

仅从当前可见的最多三辆车连续三帧同向运动推断最多两步位置。跳帧、新场、阵亡、传送、实体不完整、失去视野、保护状态不明或血量回升时丢弃对应证据。预测路径仅经过已知空格，遵守事件障碍和危险截止时间。

无预测时保持旧版静态射击位置收益；稳定运动时额外加入最多两步预测的折扣拦截候选，不削弱或删除原有静态追击候选。近期同向跟随只构成潜在追击证据，侧向射线相交只作为同收益时的位置偏好，第三方仍是完整威胁，不计其假想伤害、击杀或合作收益。攻击与即时风险仍用当前真实观测，不向裁判分数写入预测。

生产输入无裁判真值、预设地图路线或公告关键词。第一阶段、AI、协议和网关不改。候选尚须闭环场景、回归与官方模拟 AI 整场测试。
