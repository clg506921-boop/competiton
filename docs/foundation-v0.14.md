# v0.14 底层修复候选（2026-10-22）

本轮以 v0.13 为基线，只处理公共输入链路与动作检查。生产计分仍为比赛 v1.0；校内赛 v1.1 的 500 HP、死亡扣减、击杀分配尚未接入，等待完整规则确定结算顺序和字段含义。

变更：

- 分裂墙统一排除已明确观测到的本车初始出生点。证据必须是同场 Tick 0、完整存活状态、地图内坐标、`position_reason=initial`。晚加入、重生位置、其他席位出生点均不推断；爆炸不会获得出生点豁免。
- 最终 MOVE 检查增加事件墙检查，使用幻觉转换后的物理目的地。异常改 WAIT；日志 `final_guard_reason` 记录固定原因码。重复帧仍重发已检查动作。
- 排队公告的模型输入时间与校验时间都使用首次观测 Tick；原文不变，不进行本地自然语言解析。
- 非连续帧资源价值增加仅记 `collection_gaps`；已完成的普通／高价值资源任务提供数量下界，随后明确观测的独立采集再递增。日志输出 `confirmed_normal_min`、`confirmed_high_min`，不表示精确总数。

同 ID 场次重置与迟到旧包，在现有公开字段中不能可靠区分。本轮保留拒收倒退帧和退役场次的行为；若主办方允许同 ID 复用，须按正式生命周期信号或在场次边界重启本车进程，不通过超时猜测清空记忆。

正式参数继续使用 `match-settings.example.json`、`prepare_match.sh --check/--launch`。该文件只接收连接与官方公布数据，不开放策略常数。显式 v1.1 仍被兼容性检查拒绝；全文发布后应先完成源码迁移与验证，再更新支持版本，不能只改版本字符串绕过。

回归与构建结果以本轮交付的原始日志及状态卡为准；旧 v0.13 的实赛、旧九场成绩不作为 v0.14 的实赛结果。

最终验证：Release 与 ASan/UBSan 各 14 组、199 用例通过；ROS 构建、19 个启动检查、8 个接入测试、隔离域的两帧合成公开感知收发通过。官方裁判完整性匹配，本轮真实比赛和付费模型调用均为零。
