# 人工策略切换登记准备（可选）

本稿暂不把人工策略切换列为已完成或已获批准项目。若最终决定不使用，此页无需作为申请材料提交。

代码中已有decision_type预置枚举：balanced（平衡决策）与collect（采集取向），当前decision_config.json为balanced。该字段不等于ROS入口mode中的自主运行标识。

当前基线在启动配置时读取策略文件；不在报告中宣称暂停时修改文件就能自动热切换。最终若启用人工切换，需要先明确实际读取时机和运行方式，再向工作人员登记并通过验证。

待登记内容：枚举及含义、读取文件绝对路径、程序实际读取时机、批准记录、每场切换次数。只能按批准修改已登记decision_type，不得加入动作、坐标或其他算法参数。

手册规定每队每场最多2次人工策略切换，在暂停期间或加赛前申请、经批准登记后执行，恢复后生效。人工重启还另有登记和次数限制，不能把两者混为无条件许可。
