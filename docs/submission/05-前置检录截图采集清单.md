# 前置检录截图采集清单

最终版本v0.25.1-final已确定，两阶段最终镜像运行、动作和回执截图已补入报告6.3节。第一阶段100/100、第二阶段500/500，均0无效动作。感知数字坐标position也已补入6.3.4节。最终镜像两阶段练习端检录材料已齐；练习验收不等于正式审核通过。

| 图号 | 画面需要包含 | 配套说明 |
|---|---|---|
| 1 编译与启动 | 构建成功、启动命令、工程目录、版本或提交号、席位 | 用本队程序，不用参考车；显示实际启动路径 |
| 2 当前感知 | 本席位perception中的tick、session_id、self.position | 可辅助echo，但不能单独作为双向验收证明 |
| 3 合法动作 | 本队程序发布的action/direction、同帧tick/session_id | 动作字段与感知一致；不是人工逐Tick发动作 |
| 4 执行回执 | 后续感知的self.last_action，含执行Tick、动作及moved/拒绝原因 | 与图3对应同一场次和动作窗口 |

第一、第二阶段按实际程序分别留证。能合并在一张图中时也要让字段可读，不只截最终得分。

建议图注格式：

“本队程序【版本/提交号】，运行目录【路径】，第【阶段】、【席位】，场次【session_id】；感知Tick【N】、动作Tick【N】，在后续感知Tick【N+1】中确认last_action.tick=【N】。令牌未显示。”

截图中遮挡正式令牌、Authorization头、API密钥和私人信息。保留原始日志及未改动截图备查；不能把历史版本改名冒充当前版本。

本材料的“证据/v0251-本队感知动作执行闭环原始片段.json”已包含一组真实对应字段，可用于核对格式。它是日志附件，不冒充实时截图。

上传语雀时，将图片直接上传到文档，核对清晰度、图注和显示；本地相对链接不会自动替代语雀图片资源。
